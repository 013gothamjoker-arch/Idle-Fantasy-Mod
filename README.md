## 📲 Installation

1. Download the latest **`Idle_Fantasy_1_15_7_mod_gojo.apk`** from the [**Releases**](../../releases) page.
2. Install the APK on your Android device (you may need to allow *Install from unknown sources*).
3. Download **`idler_save_gojo_coins.json`** (from the same Releases page) and keep it somewhere easy to find on your phone.

> ✅ This mod uses its own package name (`idlefantasyz`), so it installs **alongside** the original Idle Fantasy. No need to uninstall anything, and your original save stays untouched!

---

## 💾 Importing the Mod Save (Required!)

The coins and boosts come from the included save file, so you **must** import it:

1. Open the game.
2. Go to **Settings → Import save**.
3. Select **`idler_save_gojo_coins.json`**.
4. Done! You should now have your boosted stats and coins 🎉

> ⚠️ Importing a save **overwrites** your current progress. Export a backup first if you care about it!

---

## ✏️ Personalizing Your Character

After importing, the save will have my default username and race. Change them to your liking:

### 🏷️ Change your username
1. Go to the **Profile** tab.
2. Tap the **edit ✏️ icon**.
3. Type your preferred username and save.

### 🧝 Change your race
1. Go to the **Profile** tab.
2. Tap the **profile icon**.
3. Pick the race you want.
